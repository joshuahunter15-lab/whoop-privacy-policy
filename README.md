# Privacy Policy – Home Assistant WHOOP Integration

This application is a private Home Assistant integration created for personal use.

## Data Access

The application may access health and fitness data made available through the WHOOP API, including recovery, sleep, strain, workout, heart-rate, and related physiological data.

## Use of Data

WHOOP data is accessed solely for display and automation within the user's private Home Assistant installation.

The application does not sell, share, distribute, or disclose WHOOP data to third parties.

## Data Storage

Any data retained by the application is stored within the user's private Home Assistant environment and is not operated as a commercial or publicly available service.

## Access and Revocation

Access to WHOOP data is authorised by the user through WHOOP's OAuth authentication system. The user may revoke access at any time through their WHOOP account.

## Contact

This application is maintained for personal use only.
